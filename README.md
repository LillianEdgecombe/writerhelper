# Character Developer Tool

An interactive tool for writers to develop detailed characters with AI-generated portraits.

## Features
- Interactive character questionnaire (CLI and Web)
- Voice and speech identification
- AI-generated character portraits via Pollinations.ai
- Export character profiles to Markdown

## Installation

### Linux / macOS
```bash
./install.sh
```

### Windows
Double-click `install.bat` or run it via Command Prompt.

## Usage

### Run CLI version
```bash
python3 main.py
```

### Run Web version
```bash
python3 main.py --web
```
Then open `http://localhost:5000` in your browser.
